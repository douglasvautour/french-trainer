# Apprenez le français !

An installable iPhone web app (PWA) for practising French verb conjugations. All progress is stored on the device.

## Files
- `index.html` – page and styles
- `app.js` – screens, quiz logic, settings, verb pages and progress
- `verbs.js` – conjugation engine, English prompts, answer checking
- `verbs-data.js` – 4,437 verbs, generated by `tools/build.py` (don't edit by hand)
- `data/lefff-verbs.tsv` – the conjugation data in readable form, extracted from the Lefff
- `data/LICENSE-LGPLLR.txt` – the licence for that data
- `tools/` – scripts and English glosses used to build `verbs-data.js`
- `sw.js`, `manifest.webmanifest`, `icons/`, `fonts/` – offline support, Home Screen icon, fonts

## Put it on your iPhone
1. Host this folder on any HTTPS static host (GitHub Pages or Netlify), with `index.html` at the top level.
2. On your iPhone, open the site's address in **Safari**.
3. Tap **Share** → **Add to Home Screen** → **Add**.
4. Open it from the Home Screen icon while online once, so it saves itself for offline use.

Always open the app from the Home Screen icon.

## Updating
Upload the changed files, then change `VERSION` in `sw.js` (for example `apprenez-v5`). The app picks up the update the next time it opens while online.

## Changing verbs or English glosses
- Conjugations: edit `data/lefff-verbs.tsv` (or re-extract it from the Lefff with `python3 tools/extract_lefff.py path/to/lefff-3.4.mlex`).
- English: edit `tools/glosses.txt` (one `verb=english` line per verb; `~verb` marks a reflexive-only verb, `!` leaves a verb out), `tools/extras.txt` (reflexive versions such as *se lever*) or `tools/common.txt` (the Common Verbs list).

Then run `python3 tools/build.py`, which rewrites `verbs-data.js`.

## Backups
Settings → Backup → **Save Backup** opens the iPhone share sheet; choose **Save to Files** (e.g. iCloud Drive). **Restore Backup** reads that file back in and replaces the current data.
